Simulation controls

Factors

General Capacity

These set the normal operating envelope: incoming traffic, fleet size, and the memory limit each container can tolerate.

Memory Pressure

The in-memory cache path holds baseline process memory plus large per-request cache state.

Request Lifetime

Longer downstream waits keep requests in memory longer.

Traffic Shape

Uneven routing concentrates work on fewer containers. This makes the same total traffic more dangerous even when fleet size is unchanged.

Failure Loop

When a container dies, capacity drops and abandoned work retries into the remaining pool.

Remediations

Fixes

Retry Deadline

Bounds how long requests hold memory while waiting on the downstream dependency, reducing the in-flight request pileup.

Concurrency Limit

Rejects new requests once a container already has too much work in flight, preventing unbounded per-process buildup.

Memory Shedding

Rejects new requests before the process reaches its hard memory limit, turning a crash into intentional load shedding.

Request flow model

Service Request Flow

Requests flow through web containers.
