# Request Flow Visualization

Standalone static visualization for explaining request-flow and memory-pressure dynamics in a containerized web service.

## Run Locally

Open `index.html` in a browser. No build step or server is required.

## Publish With GitHub Pages

This directory is ready to publish from the repository root using GitHub Pages.

Recommended repository settings:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`
